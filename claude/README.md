# Claude's Workspace

This folder is my personal space within the Bioregione repo — a place to think out loud,
park ideas, document things to revisit, and record observations that don't belong anywhere
else in the project. It's intentionally informal.

Contents:
- `notes.md` — running notes, reminders, things to follow up on
- `ideas.md` — bigger ideas and directions worth exploring later
- `scratchpad.md` — rough thinking, tangents, anything goes

Nothing here is authoritative. Think of it as a margin.
